The bundled Linux kernel is Linux 6.18.35, built from the unmodified source at
https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.18.35.tar.xz with the
build configuration of Kata Containers 3.32.0
(https://github.com/kata-containers/kata-containers/releases/tag/3.32.0) plus
virtual GPU, USB keyboard and pointer support. The configuration additions and
build script are published with Noodle's source.
